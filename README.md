☕ Projeto em Linguagem Java

📌 Sobre o Projeto

Este repositório é destinado ao desenvolvimento de aplicações e exercícios práticos utilizando a linguagem Java. O objetivo principal é consolidar conceitos fundamentais e avançados de programação, incluindo Programação Orientada a Objetos (POO), estruturas de dados e boas práticas de desenvolvimento de software.

🛠️ Tecnologias e Ferramentas

Linguagem: Java (JDK 17 ou superior recomendado)

IDE Recomendada: IntelliJ IDEA / Eclipse / VS Code

Gerenciador de Dependências: Maven / Gradle (ajuste conforme aplicável)

Controle de Versão: Git e GitHub

🎯 Conceitos Aplicados

Neste repositório, são abordados os seguintes tópicos de Java:

[x] Sintaxe Básica e Estruturas de Controle (decisão e repetição)

[x] Orientação a Objetos:

Abstração

Encapsulamento
[x] Manipulação de Coleções (List, Set, Map)

[x] Tratamento de Exceções (try-catch)

[x] Entrada e Saída de Dados (I/O)

🚀 Como Executar o Projeto

Pré-requisitos

Antes de começar, você precisará ter instalado em sua máquina:

JDK (Java Development Kit)

Git
