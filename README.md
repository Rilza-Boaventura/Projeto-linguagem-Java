# Projeto-linguagem-Java

## 📚 Sobre o Projeto

O **Projeto-linguagem-Java** foi desenvolvido para demonstrar e praticar conceitos fundamentais da linguagem Java, abordando Programação Orientada a Objetos (POO), Collections Framework e recursos modernos da linguagem.

Durante o desenvolvimento foram explorados temas como:

- Sobrescrita (Override)
- Sobrecarga (Overload)
- Switch tradicional
- Switch Expression (Java 17)
- Collections (List e Map)
- Stream API
- Optional
- Herança e Polimorfismo

---

## 🎯 Objetivo

Este projeto tem como objetivo apoiar o aprendizado dos principais conceitos da linguagem Java por meio de exemplos práticos e simples de compreender.
